# `gador` Zen / Chrome × 磨砂光影前端控制台

支持 **Zen 竖向侧边栏** 与 **Chrome 顶部标签栏** 双布局一键切换，统一融合 **磨砂玻璃 + 以光为主要渲染手段** 的视觉语言，零 C++ 重编即可自由迭代。

## 设计与交互特性

- **磨砂玻璃 × 光影渲染**：侧边栏、Chrome 顶部标签栏/工具栏、胶囊控制栏、浮层面板与对话框统一采用高饱和毛玻璃磨砂材质（`backdrop-filter: blur(28px) saturate(1.55)` + 顶边镜面高光）与动态环境光场；
- **全按钮防连点等待态（`[data-busy="true"]`）**：所有可交互按钮与异步 RPC 操作（新建/关闭空间、开关页面、抓帧、接管/交回、收起、对话框确认、VPN 策略提交、刷新与布局切换）执行期间自动锁定交互并显示磨砂流光与旋转光环，彻底防止重复点击；
- **双布局自由切换（`Alt+L` 或工具栏一键切换，自动记忆）**：
  - **Zen 竖向侧边栏模式（`data-layout="sidebar"`）**：磨砂竖向侧边栏 + 4 格 Essentials 入口 + 底部发光空间球切换 + **紧凑模式（`Ctrl+B`）** 贴边自动展开；
  - **Chrome 顶部标签栏 × 光影模式（`data-layout="chrome"`）**：Chrome 经典「圆角顶部标签条 + 居中胶囊 Omnibox + 右侧磨砂工具栏」，融合同一套环境光场、激活标签顶部霓虹光脊与右上角毛玻璃浮层；
- **悬浮地址栏（`Ctrl+L`）**：支持直接输入网址或搜索词，同时实时检索已打开的 Agent 页面（`↑↓` 选择、`Enter` 跳转、`Esc` 关闭）；
- **悬浮控制胶囊与暖光对话框**：底部磨砂胶囊提供抓帧、实时刷新、接管/交回、收起；页面 `alert` / `confirm` / `prompt` / `beforeunload` 以暖光浮卡呈现，不阻塞底层 CDP。

## 启动方式

```bash
# 1. 启动 gador 桌面无窗口守护进程
./dist/gador/bin/gador

# 2. 启动前端控制台（仅监听 127.0.0.1，带同源防 CSRF 校验）
npm run ui
# 或打包后：./dist/gador/bin/gador-ui
```

默认访问地址：`http://127.0.0.1:43118`（可通过 `GADOR_UI_PORT` 修改）。
