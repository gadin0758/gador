KERNEL SECURITY GUARD · 内核硬隔离

密码与支付强制人工接管

已强制启用
  • 密码与付款存储物理不可达

    内核完全拒绝 chrome://password-manager、chrome://settings/payments、file://、Autofill.*、WebAuthn.* 与 DOM.setFileInputFiles（ERR_DOMAIN_DENIED）。

  • 密码框与支付页强制交由人工操作

    一旦 Blink 检测到密码输入框（TEXT_INPUT_TYPE_PASSWORD）或支付/结账/银行卡流程，内核自动锁入 USER_ACTIVE 并拦截 AI（ERR_SENSITIVE_ACTION_REQUIRES_HUMAN）。

  • 接管期间零偷窥

    进入 USER_ACTIVE 后，所有 AI 写入、脚本执行与实时截屏同步冻结（ERR_HUMAN_IN_CONTROL），直到你主动交还控制权。
